# ESP32 IR Remote — เปลี่ยนมือถือเป็นรีโมททีวี

โค้ดประกอบคลิป **"เปลี่ยนมือถือเป็นรีโมททีวีด้วย ESP32"**
ติดตามได้ที่ TikTok **K iTech Review** · YouTube / Facebook **Kham iTech Lab**

ESP32 เรียนรู้ปุ่มจากรีโมทเดิม แล้วกดจากมือถือผ่าน Wi-Fi บ้านได้เลย ปุ่มที่เรียนรู้จะถูกจำไว้แม้ถอดปลั๊ก

> ใช้กับทีวี แอร์ พัดลม ที่บ้านของคุณเองนะครับ 😄

## ของที่ต้องใช้

| ชิ้น | ตัวอย่าง |
|---|---|
| บอร์ด ESP32 | ESP32 DevKit / ESP32-S3 |
| ตัวรับอินฟราเรด 38kHz | VS1838B, TSOP38238 |
| LED อินฟราเรด 940nm | 5 มม. |
| ทรานซิสเตอร์ NPN | 2N2222, S8050 |
| ตัวต้านทาน | 1kΩ (ขา B), 47Ω (LED) |

## การต่อวงจร

```
ตัวรับ IR (VS1838B)
  OUT  -> GPIO 14
  VCC  -> 3.3V
  GND  -> GND

ตัวส่ง IR
  GPIO 4 --[1kΩ]--> B  (ทรานซิสเตอร์ NPN)
                    E  -> GND
                    C  -> ขาสั้น LED IR (แคโทด)
  5V (VIN) --[47Ω]--> ขายาว LED IR (แอโนด)
```

ทำไมต้องใช้ทรานซิสเตอร์: ขา GPIO จ่ายกระแสได้น้อย ทรานซิสเตอร์ช่วยให้ LED ได้กระแสมากขึ้น ส่งได้ไกลและแรงกว่า

## วิธีใช้

1. ติดตั้ง Arduino IDE และ ESP32 board (Boards Manager → esp32 by Espressif)
2. Library Manager → ติดตั้ง **IRremoteESP8266**
3. เปิด `esp32_ir_remote/esp32_ir_remote.ino` แก้ `WIFI_SSID` กับ `WIFI_PASS`
4. อัปโหลดลงบอร์ด เปิด Serial Monitor (115200) จะเห็นเลข IP เช่น `http://192.168.1.50`
5. เปิด IP นั้นในมือถือ (ต้องต่อ Wi-Fi เดียวกัน)
6. กด **"กดเพื่อเรียนรู้"** ใต้ปุ่มที่ต้องการ → เล็งรีโมทเดิมมาที่ตัวรับ แล้วกดปุ่มหนึ่งครั้ง
7. เสร็จแล้วกดปุ่มบนหน้าเว็บเพื่อสั่งทีวีได้เลย

แก้ชื่อปุ่มได้ที่ `SLOT_NAMES` ในโค้ด

## ข้อจำกัด

- รองรับรีโมทแบบทั่วไป (NEC, Samsung, Sony, LG, RC5/RC6 ฯลฯ) ซึ่งใช้กับทีวีและพัดลมส่วนใหญ่
- **รีโมทแอร์** ส่งข้อมูลยาวกว่า (เก็บทั้งอุณหภูมิ โหมด ความแรงลม) ตัวอย่างนี้ยังไม่รองรับ ถ้าอยากได้ คอมเมนต์ในคลิปบอกได้เลย
- ถ้ากดแล้วทีวีไม่ตอบสนอง ลองหัน LED ไปทางทีวีตรง ๆ หรือเข้าใกล้ขึ้น

## อยากต่อเข้า Home Assistant

ใช้ [ESPHome](https://esphome.io/components/remote_transmitter.html) กับวงจรเดียวกันได้ ใช้ `remote_receiver` อ่านรหัส แล้วใช้ `remote_transmitter` ส่ง
